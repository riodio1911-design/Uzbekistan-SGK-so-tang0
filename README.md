# Sách giáo khoa số K12 Uzbekistan – Tầng 0 và hệ multi-agent

- `tang0/` – bộ tiêu chuẩn và thư viện dùng chung (schema, thư viện bài tập/mô phỏng, gia sư, thuật ngữ, giao diện, nhà máy media, đầu đọc dùng chung, quyết định D1–D3, CHANGELOG).
- `books/<cuon>/` – 7 cuốn đã chuyển sang `book.json` + `features.json` (bước ④).
- `kiem-ke/` – kiểm kê 7 cuốn gốc (bước ①).
- `khao-sat/` – khảo sát mẫu sóng 0 (12 PDF).
- `de-xuat/` – 65 đề xuất bổ sung tầng 0 (bước ⑥), duyệt ở D3.

Kiểm tra: `bash tang0/_cong-cu/kiem-tra-tat-ca.sh`.
